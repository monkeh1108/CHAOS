# Gridiron Lab v0.35.6 — QA

## Scope
- Stable wide pre-snap 3D camera: no tracking of selected repositioned defender; live camera follows football/carrier.
- Defenders' A/B gap fit destinations anchor to offensive linemen and do not move when the defender is manually repositioned. Visible 2D/3D assignment arrows lead to the anchored gap.
- Pregame home-team heads/tails call, randomized coin, receive/kick/defer decision, opening and second-half receiving teams.

## Passing checks
- `python build_standalone.py --check`
- `node --check src/engine.js`, `node --check src/renderer3d.js`, `node --check src/defensive_presnap.js`
- `xvfb-run -a python qa_v35_6_camera_gaps_toss.py`: 1120 px and 390 px; opening possession; camera stability; manual reposition and gap target; successful snap; home choosing receive, kick or defer produces expected first and second half kickoff selections.
- `xvfb-run -a python qa_v35_5_animation_camera.py`: 3D rendering and animation states (1120px, 390px).
- `xvfb-run -a python qa_v34_9_coverage_mesh.py`: deep coverage and Mesh traffic avoidance.
- `xvfb-run -a python qa_v35_2_browser.py`: run pursuit.
- `xvfb-run -a python qa_v31_game_flow.py`: TD, PAT, possession, kickoff and punt scenarios.

## Limitations
- Physical Xbox hardware testing is not available here.
- Tests verify tracked kickoff-selection state, not an entire played-through two-half game.
- No new OL blitz recognition or Unreal Engine port; those are future work.
- Coin toss uses a simple text popup; no animated coin mesh yet.
