# Gridiron Lab v0.35.2 — Pursuit and Experience QA

## Scope
- New pure `src/run_pursuit_policy.js` module controls edge containment, inside pursuit and backward/outside escape recognition.
- `src/engine.js` provides observed velocity/peak retreat, visible pre-snap formation, and a stable per-snap reaction roll; no hidden offensive play selection is consulted by the live pursuit policy.
- `src/defensive_memory.js` retains a left/right retreat observation only after a play finishes. Past same-formation run escapes make a rare good read possible even at PUR 60 / PRC 60; they never guarantee it.
- No changes to defensive play-calling, coverage, tackle calculations, sprint stamina, or special teams.

## Automated tests actually passed
- `python build_standalone.py --check`: generated HTML matches maintained sources.
- `node --check src/{engine,run_pursuit_policy,defensive_memory}.js`: syntax valid.
- `node qa_v35_2_pursuit.js`: left/right force, interior gap, last line, tackle proximity, ratings 99/99 vs 60/60, stable error, repeated learned pattern with chance/visible-context gates.
- `python qa_v35_2_browser.py`: integration on 1120px and 390px layouts.
- `python qa_v35_2_memory_angle.py`: four observed same-formation retreats recorded only after whistle; a deliberately favorable low-rated read improves quality (0.204 -> 0.845), and an unfavorable roll does not.
- `node qa_v35_1_memory.js` and `python qa_v35_1_browser.py`: memory regression.
- `python qa_v35_0_deep_anticipation.py`, `python qa_v34_9_coverage_mesh.py`, `python qa_v34_1_audibles.py`, `python qa_v34_4_focus.py`: pass at desktop/mobile widths.
- `python qa_v16_formation_matrix.py`: all 144 formation/front/coverage combinations pass.
- `python qa_v34_8_recovery_drag.py`: kickoff recovery and rear drag pass at both sizes.
- `python qa_v31_game_flow.py`: kickoff and scoring flow pass.
- `python qa_v33_controller_cpu_rush.py`: controller/CPU policy checks pass.

## Limits / unfinished checks
- The older `qa_v32_kickoff_control_returns.py` test stalled in the combined test batch and was not verified here. This does not imply a gameplay regression, but it remains unresolved.
- Physical Xbox controller testing and long manual games have not been done on v0.35.2.
- Recognition only considers recent, observed *backward/outside escapes* from the same visible formation. Recognition of other run concepts, scoreboard/down-distance context, and adaptive play-calling are future steps.
- The favorable 60/60 example is a controlled test of the possible outcome, NOT a claim that low-rated defenders always execute near-perfect pursuit in live games.
