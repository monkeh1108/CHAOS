# CHAOS asset provenance register

## New in v0.36.4e
- Contact lab graphics: procedurally drawn in Canvas 2D by original project-specific JavaScript; no external files, models, textures, audio, mocap or fonts added.
- Contact lab UI: inline HTML and CSS produced in `src/debug/contact_lab.js`; no external dependencies added.

## Preexisting project
- Source model primitives, visual assets, and any other preexisting media still require a complete provenance audit before commercial release; this document does not assert that every older item is cleared.

## Process for future additions
Document name, creator, URL, version/date obtained, original license text, proof of redistribution and commercial rights, attribution obligations, modifications, and storage location **before integration**. If rights are unclear, exclude or replace the asset.
