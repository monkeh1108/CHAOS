# Gridiron Lab v0.36.4c — End-Zone Kick Return Choice

## Scope
Surgical change to `src/engine.js`, built from v0.36.4b. No changes to Inside Zone, defensive adaptation, player ratings, offset return formation, or contact mechanics.

## New behavior
- A free kick fielded in the receiver's own end zone remains live; possessing it does not immediately cause an automatic touchback.
- Human-controlled returner: two-second neutral-input grace period after fielding. Any directional movement commits to a return; remaining neutral awards a touchback. This is a GAME convenience, not an NFL officiating timer.
- CPU receiver: live automatic return decision, no human grace period.
- A deliberate give-up or completed tackle before advancing out of the end zone is ruled a touchback, not a drive starting at the one.
- A genuinely unfielded direct deep kick remains a touchback. The code distinguishes the 35-yard result for a direct deep kick from the 20-yard result for a kick that first landed in the landing zone and subsequently entered the end zone. Punt behavior is intentionally unchanged.

## Remaining limitations
- Two-second automatic touchback is an optional input convenience and differs from literal NFL procedure (which uses deliberate downing or other dead-ball conditions).
- Kick bounce remains a simplified model; no orientation- or spin-driven physics yet.
- Crowded contact separation can still cause noticeable player corrections; no change to collision solver this patch.
- Returner re-entering his own end zone after carrying the ball into the field of play requires a separate complete NFL impetus/safety rules audit.
- Physical controller and full-match play testing still required.
