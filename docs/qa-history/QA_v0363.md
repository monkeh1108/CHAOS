# Gridiron Lab v0.36.3 — QA Results

## Scope: six approved corrections
1. **Facing and pre-snap arm pose** — defensive players initialize facing the offense; offense faces downfield. All pre-snap ready stances now point arms forward instead of backward.
2. **Goal-line formation compression** — each defender's starting depth is compressed only when that original depth would extend toward the end zone; hard boundary is opponent goal line +4.65 yards (approximately 5 yards into the end zone). Deep zone anchors and reactive deep coverage now use compatible end-zone bounds; the renderer and play art consume those actual targets.
3. **Dive commitment and cooldown** — ball carrier cannot restart a dive in progress; user defensive dive sets recovery/cooldown. A missed defensive dive transitions into fall, ground recovery and rise using the common `tickGround` lifecycle.
4. **Getting-up poses** — 3D player limbs plant and fold during knockdown/rise; existing pancake/contact knockdowns share the same pose system. These are procedural, not skeletal/motion-captured animations.
5. **Block spacing** — an engaged blocker/rusher pair has a mass-weighted short separation correction, preventing body-mesh intersection while retaining existing blocking physics and shed checks.
6. **Mesh spacing** — staggered shallow-cross route depths, amplified live teammate avoidance, a route-pair separation cushion, and no injury-like ground knockdowns solely from two Mesh receivers brushing each other.
