# Gridiron Lab v0.36.0 — game-flow and return-blocking checks

## Changes
- Q2 expiration now enters an explicit halted `halftime` state. The score and second-half receiving team appear in the post-play overlay. Continue with the action button, Enter, or controller A. Q3 kickoff is created only on continue.
- Quarter expiration at a dead-ball transition is checked even when `postWhistle` is set; previously a state could remain unresolved when the play ended at 0:00.
- Play-clock expiration uses a dedicated `applyDelayOfGame()` function for user and CPU pre-snap states: five-yard penalty, replay down, and reset to a fresh play. Normal CPU auto-snap still generally occurs before timeout.
- An unobtrusive state label reports whether the game is waiting for a play, CPU, halftime continue, kickoff, or live possession. A debug match summary includes penalty count, phase, and the latest flow note.
- Kickoff return blockers keep an active engagement, aim at an intercept point rather than the defender's current position, and may initiate contact from a slightly wider near-contact range. This is a conservative tuning, not a full blocking-physics rebuild.

## Limitations
- Actual physical Xbox-controller behavior is not tested in this environment.
- Basic browser kickoff tests confirm live execution and return blocking intents, NOT realistic success rate. User should evaluate return blocking during several kickoffs.
- Halftime was checked with controlled game-clock settings, not by playing all four quarters manually.
- Return-ball teleportation/loose-ball physics and the full game-options menu are unchanged.
- PASS: Grounded special-teams player checks now correctly compare player keys (previously compared entire player objects against a Set of keys), preventing knocked-down athletes from being given ordinary pursuit/blocking movement before recovery. Return smoke rechecked afterward.
