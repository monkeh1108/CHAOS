# Gridiron Lab v0.34.7 — sideline recovery and secured return tackles

## Scope
- Keep kickoff coverage players from trying to bypass an engaged blocker by running outside the left/right field boundary. Bypass target is now relative to the blocker, rather than a small offset of the returner's target location.
- Stale block flags no longer prevent tackle initiation if a coverage player has actually reached the returner and no active nearby blocker is maintaining that engagement.
- Prevent starting a new blocking engagement when the defender already has a tackle grip.
- A sustained, secured wrap on a returner completes when the runner is slow, exhausted, or multiple defenders are engaged. Breakable tackles still use existing rating/leverage/escape calculations.

## Limitations

- Physical Xbox hardware not tested. Kickoff landing teleport and bouncing balls unchanged.
