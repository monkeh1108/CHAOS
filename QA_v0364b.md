# Gridiron Lab v0.36.4b — focused QA

## Changes
- Own-goal-line crossing during a live run no longer triggers an automatic safety. An actual dead-ball tackle, sack, dive-down or out-of-bounds event in the offensive end zone does trigger a safety.
- A legitimate safety awards two points and follows with a `safety-kick` state (kicking team at its own 20), not an ordinary kickoff.
- Inside Zone blockers maintain secured contact slightly longer near a threatened runner lane. This is deliberately modest and rating-dependent, not an animation lock.
- Deep returners start separated across left and right lanes. The system selects the more feasible fielding athlete, not a fixed primary.
- Removed the position assignment that teleported a returner to the landing spot. An actual catch/recovery requires physical proximity; an unfielded ball remains on the ground with a *temporary simplified damped bounce and roll*.
- Coverage and blocking players resume moving after landing while the ball remains loose.

## Open issues / NOT yet implemented
- This is NOT a rigid-body football bounce simulation. There is no orientation, nose/side impact shape, angular velocity, or user-controlled spin. Bounce and roll are deliberately provisional, and kick power does not yet determine the restitution of each bounce.
- Kicking-team loose-ball recovery and full legal punt/downing/fair-catch rules require a separate rule-complete pass. Full 2026 dynamic kickoff setup and touchback rule compliance still need auditing.
- Existing crowd-collision solver can create too-large per-frame position corrections, despite the old landing-position teleport being removed.
- Older unseeded `qa_v36_4_zone_iq.py` was flaky in one mobile run (random alignment produced no double-team); other focused run intelligence checks were already validated in v0.36.4. Do not call this a clean pass.
- Long-drive human gameplay feel remains unverified; this is a targeted test build.
