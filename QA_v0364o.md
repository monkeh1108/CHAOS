# CHAOS v0.36.4o — Break Tackle / Wrap Break QA

## Scope
- Added `src/tackle_escape.js`, a deterministic, frame-integrated leg-drive versus grip contest; connected it to active tackles in `src/engine.js`.
- Different escape thresholds for unsecure holds/ordinary tackles and a well-placed secured wrap. The initial link must come from existing physical contact: no contact => no link => no break event.
- Existing ratings have differentiated roles: STR lower-body force; TRK collision resilience/power; ACC ability to keep leg drive; stamina endurance; balance and forward traction; defender TAK/AWR hold technique, STR resistance; actual grip and anatomy quality and relative separation are considered. No new GRIP rating, no unlicensed assets, no animation lock.
- New debug function `debugEscapeContests()` returns current active tackle diagnostics. Physical progress remains an approximate model, not real foot-ground simulation.

## Known limits and manual verification
- Initial prototype escape calculation is continuous and physics-informed, but still heuristic; sustained grip, collision contact and strength can need balance tuning from full-game play.
- Player-specific planted foot traction, footstep animation, two-hand wrap grip geometry, multi-defender escape coordination, tackle feedback UI, and full-body falling remain future work.
- This is not a claim of verified full-match human gameplay. Test both weaker defenders' arm grabs and well-secured tacklers in an actual game; inspect whether there are too many or too few breakaways.
