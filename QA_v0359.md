# Gridiron Lab v0.35.9 QA

## Changes
- Defensive pre-snap RT/Shift multiplies position movement by 1.45 (quick jog); no stamina touched by the movement module. LOS and teammate collision limits stay intact.
- Kickoff-return blockers prioritize approaching threats in the returner's lane and lead moving targets, instead of selecting mostly on blocker proximity.
- Preserved existing special-teams tackle/recovery, receiving logic, and in-play controls.

## Verified
- Standalone builder output matches source; JavaScript syntax succeeds.
- `node qa_v35_9_policy.js`: faster pre-snap jog, no stamina mutation, bounded movement, threat selection/claimed targets.
- `python qa_v35_9_return_smoke.py`: kickoff browser test desktop (1120) and mobile (390), no browser JS errors, return AI assignments activated.
- `python qa_v35_4_presnap_position.py`: pre-snap movement, assignments, snap and audibles at both widths.
- `node qa_v33_policy_unit.js`: older module tests.
- `xvfb-run -a python qa_v35_6_camera_gaps_toss.py`: coin toss and camera at both widths.
- `python qa_v35_8_blitz_sack.py`: safety QB sack.
- `python qa_v35_7_protection_quickgame.py`: 1-minute quarters and blitz recognition.

## Limitations
- Existing `qa_v32_kickoff_control_returns.py` fails at obsolete return-call menu structure, before gameplay.
- Existing `qa_v31_game_flow.py` assumes 15-minute quarters; this build intentionally uses 1-minute quarters.
- Return blocking improvements are tuning, not proof that all live kickoffs have ideal blocks; real-controller and prolonged game tests remain necessary.
- Future size/strength-aware block avoidance is proposed, not implemented in this version.
