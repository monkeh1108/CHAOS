# Gridiron Lab v0.35.5 — Camera and Modular Animation QA

## Scope
- Built from v0.35.4 as a small visual-only update.
- Wider pre-snap 3D framing follows the line/selected defender rather than zooming tightly on one player. Normal live camera follows the ball as before. Special teams retain prior camera behavior.
- `src/animation_policy.js` is read-only: identifies movement/contact/air/catch/knockdown and existing move actions and returns pose modifiers for the renderer. No changes to collision outcomes, speeds, stamina, coverage AI, or player assignments.

## Checks performed
- `node --check` for maintained JavaScript source and `python build_standalone.py --check`: PASS.
- `xvfb-run -a python qa_v35_5_animation_camera.py`: PASS at desktop 1120px and narrow 390px. WebGL initialized; pose states distinguished idle, sprint, engaged, juke, hit stick, airborne catch, knockdown, get-up, spin. Camera desired zoom changed on snap, and no page exceptions were recorded.
- Existing v0.35.4 pre-snap positioning / assignment browser tests: PASS at 1120px / 390px.
- Existing v0.35.0 deep anticipation, v0.34.9 Mesh coverage, v0.34.1 audibles, v0.35.3 interception, v0.35.1 memory, v0.35.2 pursuit browser tests: PASS.

- 144 formation/front/coverage/run-play combination test: PASS.
- v0.33 policy, v0.35.1 defensive memory, v0.35.2 pursuit unit checks (Node): PASS.

## Known limitations
- New animation policy is a foundation for future animation variety; it does not introduce high-detail character models, skeletal rigging, advanced blending, hit-stick collision physics, or fumbles. Existing action animations remain in place.
- A virtual-display software WebGL environment is slower than a real GPU. Tests confirm framing behavior, not a specific frame rate.
- Physical Xbox controller input, long-session performance, and all kickoff edge cases were not exhaustively tested in this pass. The previous flaky older kickoff tests are not claimed as resolved.

2. Move a safety with the left stick, then release before the CPU snap. The visible assignment and behavior should still agree.
3. Repeat on offense, then snap with A. The camera should smoothly move back to tracking the live action.
4. Compare sprinting, contact, jukes, jumps, catching, falling, and getting up. Animations should still correspond to actual player state.
5. Confirm existing audibles, run defense, stamina, kickoffs and tackling feel unchanged.
